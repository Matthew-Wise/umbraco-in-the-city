## Project Overview

Conference website for "Umbraco In The City" (Manchester). Two-part stack:
- **Frontend**: Next.js 15 (App Router) + TypeScript + Tailwind + shadcn/ui
- **Backend**: Umbraco 17 CMS on .NET 10, exposing content via Delivery API
