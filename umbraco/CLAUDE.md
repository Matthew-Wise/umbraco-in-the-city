# Umbraco CMS Project
Responsible for content managment. Delivers content to the frontend project using the [Content Delivery API](https://docs.umbraco.com/umbraco-cms/develop-with-umbraco/headless-and-apis/content-delivery-api)

# Controlling CMS Data
This should be done my the user, when making content modeling descisions give the user a breakdown of how to model the content in the CMS, and verify using the generated Models Builder models in `~/umbraco/models`

# Coding standards
Ensure things are not using Obsolete implomentaions, and we keep warnings to a minimum.

# Running the project
Where possible use dotnet watch to minimize downtime, but be aware that something wont change until you fully restart.
